# 1. Focus 0.3.2／Usage 0.3.1 候選收尾

這是工具箱0.16的本機未發布候選；不修改031或已發布版本。來源檔存在和SDK記憶體終端測試不等於目前對話已重載或實體畫面通過。

## 1.1 錯誤與二層收合

普通唯讀工具錯誤原文收到思考／工具群組內，不再因isError強制攤開整塊輸出；錯誤計數與紅色群組標題保留。錯誤安全pin、原raw/isError/退出碼、模型輸入與session歷史不變。未知renderer／真正輸入／授權仍留原生，不能因折疊錯誤而隱藏確認。

每次打開群組詳情，各思考段／每次工具呼叫預設一行，工具參數與結果同一項，顯示工具名／狀態／耗時與簡短參數。點標題原位展收，各項獨立，不疊第二個彈窗；長輸出僅展開時渲染，原文不摘要、不截斷保存、不呼叫模型。

群組詳情每次從清單底部開啟，不自動展開最後一項。Enter或空白切換選中項，↑↓選項，PgUp/PgDn捲動，Home/End到頭尾，c全部收合，Esc／Ctrl+C只關閉詳情。操作列有全部收合與到底部。選字拖曳不切換標題；展收保持標題錨點；手動上捲後不強拉，新增項提示在到底部按鈕。其他資訊／完整歷史預設起點不改。

滑鼠依原生終端模式能力，regular保留鍵盤路徑，不強切fullscreen。圖片仍維持031原生單一Image owner／主畫面來源路徑，不搬入文字詳情；普通正文與write原邏輯保持。

# 2. 同一Footer的自動重置提示

有本分支有效自動用卡grant（once／each）時，在既有subscription-usage狀態加上：

`ACM 20%/25% 204K/250K  │  額度 7 天剩 30%  │  已啟用自動重置 1 次`

數字為既有帳本limit-used-held的剩餘允許次數，不是卡片庫存或原設定上限。Off／沒有grant不顯示；處理中與未知預算明示，不使用舊數字；保留/UNKNOWN標待對帳。成功耗盡後沿既有策略Off移除提示，重載/分支/模型切換不默啟。

這是純顯示投影，不保存新授權、不增加HTTP/卡/模型請求，不把Goal quotaRecovery誤認為用卡授權；手動暫停仍優先，既有有限N/資格/去重/UNKNOWN先對帳安全機器不變。
